# Claude Instructions

Read AGENTS.md first and follow it as the shared source of engineering rules.

Before implementing a feature:
1. Read the relevant feature specification.
2. Inspect the existing code and tests.
3. Propose a plan for changes spanning more than three files.
4. Respect docs/api/contract.md and docs/api/openapi.yaml.
5. Add or update tests.
6. Summarize files changed, verification performed, and remaining risks.

Do not invent requirements or silently change architecture decisions.
